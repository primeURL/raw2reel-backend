# Sound effects

Rendered with earshot (https://github.com/Leonxlnx/earshot, MIT) by `scripts/make_sfx_pack.py`.
earshot's licence: everything it renders belongs to whoever rendered it, free for any use,
commercial too, without credit. Its realistic designs are rebuilt from CC0 / public-domain
recordings (credited in earshot's own `earshot/data/*/CREDITS.md`).

| file | earshot design | used for |
|---|---|---|
| whoosh_fast_{1,2,3}.ogg | whoosh/fast | punch in |
| whoosh_soft_{1,2,3}.ogg | whoosh/soft | slow push |
| boom_{1,2,3}.ogg | boom/deep | spotlight |
| slam_{1,2,3}.ogg | slam/title | word behind you, flash |
| shutter_{1,2,3}.ogg | camera/shutter | freeze frame |
| tick_{1,2,3}.ogg | clock/tick | countdown |
| pop_{1,2,3}.ogg | pop/soft | captions appearing (punchy) |
